## 0. 合规与商业模式前提（硬约束）

- v1.0 只做 **IAA（激励视频广告）** 变现；内购 / 月卡 / 免广告 = 版号后置，仅预留接口。
- 开发者主体：**个人开发者**。上线前必须确认两件事，且应最先启动（与开发并行）：
  1. 微信官方确认"放置修仙"题材可归类的二级类目（个人主体不支持部分类目，存在被驳回风险）；
  2. 小程序备案（平台初审 + 主管部门，合计约 4–8 周），未备案不能发布。
- 分享合规（微信红线）：**无助力、无强制分享、无多级累积奖励**；分享 = 单次、非强制、小额奖励。

## 1. 核心循环（定稿）

- 主动层：**神游**（点击 / 自动）→ 每次触发 1 次**奇遇** → 资源 / 图纸 / 神游石 / 少量灵力
- 成长层：**自动修炼**（灵力主来源）→ 小境界突破 → 大境界突破（概率 / 渡劫）→ 战力提升
- 推进层：**Boss**（每境 中期 + 圆满 各 1 个，共 18 个）→ 首通图纸材料 + 扫荡材料 → 炼宝阁打造 / 商店
- 重置层：金丹后首次挑战当前 Boss 失败 → **主动轮回** → 保留装备 / 药方 / 50% 神游石 / 宗门，重新爬境
- 后续版本：渡劫境圆满 + 18 Boss 全通 → **通关轮回**（换职业 / 永久成长）

## 2. 境界与突破（定稿）

- 9 大境界：炼气 / 筑基 / 金丹 / 元婴 / 化神 / 炼虚 / 合体 / 大乘 / 渡劫境。
- 每大境界 = 前期 → 中期 → 后期 → 圆满；**每个小境界（含圆满阶段）先积累对应档位灵力，达标后突破**：小境界推进直接成功，圆满 → 下一大境界按 100% 保底 / 概率 / 渡劫判定；**渡劫境除外**（渡劫境内每个小境界都需渡劫）。
- 大境界突破规则：
  - 炼气 → 筑基：**100% 保底**（新手第一跳）。
  - 筑基 → 金丹：**真实概率**，基础 ≥80%，丹药 / 运气属性可提升。
  - 金丹 → 元婴 起至 大乘 → 渡劫境：共 6 次大境界突破均需**渡劫**；渡劫境内再叠加 3 次小境界渡劫（终局共 4 连劫）。
- 突破 / 渡劫**成功**：当前境界灵力**清空重攒**。
- 突破失败（筑基 → 金丹）：不扣已积累灵力；**修为进度锁定，需再补约 10% 灵力才可再试**。
- 渡劫失败：**扣当前小境界进度的 5%**；**失败保底：连续失败每次 +5% 成功率直至上限**。
- 渡劫成功率：`30% 基础 + 战力系数加成 + 体质加成 + 运气加成 + 丹药加成`，**硬上限 95%**（已删除"计算值>300% 即必成"规则）。

## 3. 神游石（定稿）

- 上限 **500**；倒计时恢复 **1 点 / 30 秒**，被动只恢复到 **30**（超过部分仅靠奇遇 / 突破）。
- 突破成功一次性 **+50**；奇遇**小概率**回石（概率 / 数值待定）。
- 每次神游消耗 **1** 神游石；**神游石是唯一闸门**，无额外每日次数限制。
- 手动连点冷却建议 ≥0.5s（防脚本）；自动神游仅**在线**运行，**2 秒 / 次**。
- 主动轮回：神游石保留 **50%**。
- 可选广告位：看激励视频 + 神游石（数值待定）。

## 4. 奇遇引擎（主玩法，定稿）

- 轻量 : 完整 = **80 : 20**。
- 轻量奇遇：不弹窗，底部浮层直接结算；**模板 × 当前境界参数**动态生成（妖兽袭击 / 药材发现 / 材料发现 / 灵石堆等）。
- 完整奇遇：二选一 / 点击小游戏（手写 + 模板化）；触发选择类时给 **3 秒倒计时**，超时自动选**保守项**；自动模式下互动类按基础概率直接结算、不弹小游戏。
- 奇遇可产出：灵石 / 药材 / 打造材料 / 神游石 / 少量灵力 / 临时 buff（权重与数值待定）。

- P1 首轮神游配置（2026-09-21 确认）：
  - 初始神游石 30；每次消耗 1；1 点 / 30 秒恢复，被动上限 30；手动冷却 0.5 秒；自动在线每 2 秒一次。
  - 收益 01 凝神吐纳：修为 +10 基础单位。
  - 收益 02 灵石矿脉：灵石 +10。
  - 选择 01 集市冲突：A 分支灵石 +5；B 分支无奖励；自动结算 A 分支概率 50%。
  - 选择 02 深潭巨蟒：A 分支灵石 +5、修为 +10 基础单位；B 分支无奖励；自动结算 A 分支概率 50%。
  - 稀有 01 无名功法残页：修为 +30 基础单位。
  - 稀有 02 法宝现世：折算为灵石 +100。
- 选择类奇遇弹窗延期：当前开发阶段先以“自动结算 A 分支概率 50%”作为占位；待奇遇事件弹窗、选项按钮和选择类光效素材完成后，再替换为手动选择和 3 秒倒计时。
- 旧规则"每提升 20% 修为有 20% 概率触发奇遇"**作废删除**。

## 5. 灵力经济

- 获取公式（定稿）：`灵力获取 = 基础值 × (1 + 灵根加成) × (1 + 宗门大殿加成) × (1 + 首饰加成 + 法宝加成)`
  - `基础值`：按公式定稿 v0.5 的 P1 境界基础值每 5 秒结算。开发构建可启用 5× 时间倍率，用于 P1 原型约 20–30 分钟走通至金丹和主动轮回；正式构建固定 1×。旧“单档约 2.8 小时、全流程约 100 小时”作废，最终节奏在 P3 按测试数据调整。
- 灵力需求表：9 大境界 × 小境界阈值（前期 / 中期 / 后期 / 圆满），原表只到元婴，需补化神 ~ 渡劫境。
- 离线：收益系数 = 在线的 50%（已定）；封顶时长（建议 8–12h）待定。
- 突破 / 渡劫成功后灵力清空（见第 2 节）。

## 6. Boss 与装备（定稿）

- **共 18 个 Boss**：每大境界 1 个"中期 Boss" + 1 个"圆满 Boss"。v1.0（炼气 ~ 元婴）= 8 个。
- 首通掉落：**图纸按未拥有类型补缺发放**（武器/防具/首饰缺哪类给哪类，不重复）+ 打造材料；扫荡：获得**打造材料**。
- **Boss 进度跨轮回重置**（已确认，不保留）；Boss **不卡境界突破**，目的 = 装备图纸 / 升星材料 / 轮回前提（通关轮回需全通 18 个；Boss 顺序解锁：通关一个解锁下一个）。
- 装备品阶来源：
  - 黄 / 玄阶武器、防具、首饰：商店高概率刷新。
  - 地阶：商店小概率刷新；也可打造。
  - 天 / 神阶：仅打造 / 奇遇（奇遇只给图纸）——内容后置，v1.0 不做。
- 穿戴限制：黄 / 玄阶无限制；地 / 天 / 神阶有**境界门槛**，低境界穿戴时属性**按比例衰减**，境界提升后逐渐解锁（衰减公式待定）。
- 升星：消耗矿场材料 + Boss 扫荡材料（原"仅矿场"改为双来源）。
- 武器严格限职业（剑 / 枪 / 刀）；防具 / 首饰不限。

## 7. 炼宝阁（金丹解锁，v1.0）

- 原"炼丹房"取消，并入**炼宝阁**：内置**炼丹** + **打造**。
- 打造需：特定**打造图纸 + 打造材料**；覆盖**地 / 天 / 神**阶（v1.0 只做到地阶，天 / 神规则预留）。
- 打造成功率 / 是否耗时：待定（建议 v1.0 打造 100% 成功、无耗时，只吃材料与图纸，减少挫败与实现成本）。
- 炼丹：v1.0 种子丹方集（疗伤 + 突破类，原 22 种裁剪）；丹方 / 药材 / 辅助药材数值待定。

## 8. 宗门（2026-09-28 修订：v1.0 含全部 5 栋）

> **变更说明**：原文「弟子招募 / 派驻、演武场：整体后置 v1.1」**已作废**。经 2026-09-28 确认，弟子招募 / 派驻、演武场**全部提前到当前批次制作**，宗门 v1.0 由 3 栋扩为 5 栋。

- 宗门共 5 栋建筑：大殿、炼宝阁、矿场、演武场、纳贤阁。
- 大殿：每级灵力加成 %，升级消耗（待定）；**每驻 1 名弟子，全局产出额外 +2%**（叠加在等级加成之上）。
- 矿场：金丹解锁，自动产出（灵石 : 打造材料 = 80 : 20），仓库上限、提取规则（待定）；**每驻 1 名弟子，按弟子等级提升产出**。
- 炼宝阁：见第 7 节；**每驻 1 名弟子，按弟子等级提升炼丹成功率**。
- 演武场：每级灵力产出 +4%（与战斗公式中战力加成的合并关系待理清）；**每驻 1 名弟子，战力 +3%**。
- 纳贤阁：**弟子招募主入口**（次要来源为奇遇掉落），并负责**弟子升级**；**每驻 1 名弟子，提升招募速度**。

### 8.1 弟子系统（2026-09-28 新增，原 v1.1 提前）

- 获取：**主要通过纳贤阁招募**，次要通过奇遇获得。
- 稀缺性：**一名弟子只能派驻一处**；每栋建筑 2 个弟子位，5 栋共 10 位；**弟子总量上限 10**。
- 等级：**弟子有等级**，升级入口在**纳贤阁内的二级小窗**（升级消耗、等级上限待定）。
- ⚠️ **数值口径冲突（必须同步修正）**：原公式把「派驻弟子」当作固定 +1 单位。弟子一旦有等级，矿场 `(1 + 派驻弟子)`、炼宝阁 `派驻弟子 × 3%` 必须改为 `Σ(弟子等级 × 系数)`，否则弟子升级不会影响派驻产出。

## 9. 商店（规则沿用原案，数值待定）

- 每日 0 点自动刷新 1 次 + 免费手动刷新 5 次；之后灵石刷新，每累计 5 次阶梯涨价，次日重置。
- 商品：黄 / 玄 / 地阶装备、药方、药材、材料、图纸（图纸是否入商店待定）。
- 商店等级：解锁品阶 / 概率加成 / 升级消耗（待定）。

## 10. 轮回（定稿）

- **主动轮回（v1.0）**：
  - 解锁：境界达到 **金丹**，且首次挑战当前 Boss 失败后即可点。
  - 保留：4 件装备 + 3 份药方 + **50% 神游石** + 宗门建筑 + 天赋重配；职业不可更换；**打造图纸不保留**（每轮重新收集）。
  - **不给永久收益**（无天赋上限增加、无执念）。
  - 难度：**不变**（定位为"带装备重试工具"；加难度的是通关轮回）。
  - Boss 进度重置（重新爬境、重新首通拿图纸材料）。
- **通关轮回（后续版本）**：
  - 触发：渡劫境圆满 + 18 Boss 全通（强制）。
  - 难度增长：**每轮 +15%**（沿用原案），**累计上限 +100%**，到顶后不再增长；可换职业；每轮 +5 天赋上限；执念叠加（每轮 +X% 对应职业基础伤害）；结算灵石；保留全部药方 + 1 法宝 + 宗门；**打造图纸全保留（图鉴式）**。

## 1 职业与天赋

- 灵力获取效率 = 1 + 灵根点数 × 0.02
- 渡劫成功率加成 = 运气点数 × 0.015
- 炼丹成功率加成 = 精神力点数 × 0.02
- 体质战力加成 = 1 + 体质点数 × 0.03
- 商店高价值概率加成 = 运气点数 × 0.01
- 职业系数（剑/枪/刀）：攻速 1.2/1.0/0.8；伤害 1.0/1.1/1.3

## 2 修炼与境界

- 第 N 大境界圆满灵力 = 10^(N+2)（炼气 N=1 → 1000；筑基 10000；…；渡劫境 N=9 → 10^11）
- 小阶段进度门槛 = 大境界总灵力 × 阶段比例：前期 25% / 中期 50% / 后期 75% / 圆满 100%
- 基础灵力（每 5 秒）= P1 × 灵力获取效率 × 宗门大殿加成 × 修为增益buff × (1 + 首饰灵力词条 + 法宝灵力加成)
- 结算口径：大境界内灵力到达当前小阶段门槛后突破；每次突破成功后扣除本次所需灵力，剩余灵力结转到下一阶段继续沿用。

## 3 渡劫

- 最终成功率 = 基础 30% + 运气点数×1.5% + 体质点数×0.5% + 战力差距加成 + 丹药加成
- 战力差距加成 = (当前战力 ÷ 推荐战力 − 1) × 20%，上限 +30%
- 丹药加成 = 单颗突破丹 +15%，最多 1 颗
- 失败惩罚 = 当前大境界已累计灵力的 5%
- 硬上限 95%；连续失败每次 +5% 保底直至上限
- 需渡劫：元婴起 6 次大境界突破 + 渡劫境内每个小境界突破

## 4 战斗与技能

- 普攻秒伤 = (P21 玩家基础战力×体质加成 + 装备总战力 + 法宝战力 + 演武场加成) × 职业攻速系数 × 职业伤害系数 × (1 − Boss对应抗性 + 装备减抗词条)
- 技能单次伤害 = 普攻秒伤 × 技能伤害系数 × (1 − Boss对应抗性 + 装备减抗词条)
- 技能实际冷却 = 基础冷却 × (1 − 首饰冷却缩减词条)
- 受击秒伤 = Boss普攻伤害 × (1 − 防具伤害减免词条)
- 技能伤害系数 = 品阶基准 × 职业系数；品阶基准占位：黄 1.0 / 玄 1.5 / 地 2.5 / 天 4.0 / 神 6.0（具体技能表待补）

## 5 Boss 关卡

- 18 个 Boss：每境中期 = 普通（战血 ×8）、每境圆满 = 大境界最终（战血 ×15）
- Boss 血量 = 推荐战力 × 战血系数
- Boss 普攻秒伤 = 推荐战力 × 0.1 × (1 + 通关轮回次数 × 0.15)
- 首通掉落：灵石 = 推荐战力 × 0.5；灵力 = 当前境界满灵力 × 10%；技能/装备概率掉落 = 50%；图纸按未拥有类型补缺发放
- 扫荡产出：灵石 = 首通灵石 × 30%；材料 = 该关首通材料量 × 20%（该关首通材料量为逐关参数，待定）
- 商店刷新基础概率：神 0.5% / 天 1% / 地 5% / 玄 15% / 黄 20%（按单个刷新位）

## 6 宗门与矿场

- 宗门共 **5 栋**：大殿、炼宝阁、矿场、演武场、纳贤阁（2026-09-28：演武场、纳贤阁由 v1.1 提前至当前批次）。
- 建筑升级消耗 = 基础消耗 × 1.8^(等级−1)；建筑加成 = 等级 × 单级加成值；最高 10 级
- 大殿：基础消耗 5000，全局产出 +5%/级（灵力、灵石、材料）；**每驻 1 名弟子，全局产出额外 +2%**
- 炼宝阁：基础消耗 3000，炼制成功率 +3%/级；**每驻 1 名弟子，按弟子等级提升炼丹成功率**
- 矿场：基础消耗 4000，挖矿产出与存储上限 +10%/级；**每驻 1 名弟子，按弟子等级提升产出**
- 演武场：基础消耗 6000，灵力产出 +4%/级（与战斗公式中战力加成的合并待理清）；**每驻 1 名弟子，战力 +3%**
- 纳贤阁：基础消耗待定；弟子招募主入口 + 弟子升级入口；**每驻 1 名弟子，提升招募速度**
- 弟子派驻口径：一名弟子只能驻一处；每栋 2 位，共 10 位；弟子总量上限 10
- 矿场：灵石/h = 基础 100 × 1.1^(等级−1) × **(1 + Σ(弟子等级 × 系数))** × 大殿加成；材料/h = 灵石/h × 0.1（约 10:1）；1 级存储合计 1000，按等级加成
- 储量满停止产出并推送提示；手动提取后清空恢复

## 7 炼宝阁（炼丹 / 炼器）

- 炼丹成功率 = 基础成功率 + 炼宝阁等级 ×3% + 精神力点数×2% + **Σ(弟子等级 × 系数)（≤2 人；即原「派驻弟子×3%」改按弟子等级计算）** + 辅助药材×5%（≤2 种 +10%）
- 基础成功率：黄 70% / 玄 50% / 地 30% / 天 15% / 神 5%
- 打造（炼器）成功率：基础同品阶（70/50/30/15/5）+ 炼宝阁等级加成；不吃精神力/药材/弟子
- 丹劫触发：地 20% / 天 35% / 神 50%；极品丹效果 = 普通丹 × 5

## 8 装备

- 最终战力 = 基础战力 × (1 + 星级 × 0.1)；词条数值 = 基础词条值 × (1 + 星级 × 0.1)
- 装备出售价 = 基础战力 × 2 × 星级系数；星级系数 = 1 + 星 × 0.5
- 商店售价 = 出售价 × 1.5
- 来源：黄/玄 = 商店高概率；地 = 商店小概率 + 打造；天/神 = 商店（4~5 级直接购成品）+ 打造 + 奇遇图纸
- 穿戴：黄/玄无限制；地 = 金丹门槛、天 = 化神门槛、神 = 大乘门槛（低境界穿戴衰减规则待补）
- 武器严格限职业（剑/枪/刀）；防具/首饰通用

## 9 法宝

- 加成效果 = 基础加成 × 品阶系数
- 单属性基础加成：地 20% / 天 30% / 神 50%；词条数：地 1 / 天 2 / 神 2–3
- 词条池沿用：战力 / 灵力 / 体质 / 运气 / 商店折扣 / 刷新概率（词条数值待定）

## 10 商店

- 高价值商品刷新概率 = 基础概率 × (1 + 商店等级×0.1 + 运气点数×0.01 + 法宝加成)
- 付费刷新价 = 100 × 2^floor(当前付费刷新次数 ÷ 5)；每日 0 点重置；免费手动刷新 5 次/日
- 商店等级解锁：1 级黄 / 2 级黄玄 / 3 级黄玄地 / 4 级+天 / 5 级全部品阶（直接购成品，无需打造）

## 11 奇遇与神游

- 神游触发类型权重：收益 50% / 选择 45% / 稀有 5%
- 修为进度触发：达到阶段门槛（25/50/75/100%）时各 roll 20% 概率，只触发稀有类奇遇，每大境界最多 5 次
- 神游石：上限 500；倒计时 1 点/30 秒恢复至 30；突破成功 +50；每次神游消耗 1；手动连点冷却 0.5s；自动在线 2 秒/次
- 选择类：3 秒倒计时，超时自动选保守项；自动模式互动类按基础概率直接结算

## 12 轮回

- 主动轮回：境界 ≥ 金丹且首次挑战当前 Boss 失败后可点；保留 4 装备 + 3 药方 + 50% 神游石 + 宗门 + 天赋重配；职业不可换；Boss 进度重置；难度不变
- 通关轮回：难度每轮 +15%、累计上限 +100%；天赋每轮 +5（总 ≤100）；可换职业；图纸与药方全保留（图鉴式）；执念每层 +5%（剑/枪/刀意各自），每通关轮回 +1 层，累计上限 16 层（80%）
- Boss 秒伤公式中的轮回次数 = 通关轮回次数（不含主动轮回）
